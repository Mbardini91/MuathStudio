# Muath Studio

Portfolio website for Muath Studio, the branding, motion and media practice of Muath Albardini (Bahrain).

A single static page with no build step: `index.html` plus the `assets/` folder.

## Run locally

Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8000
```

## Publish with GitHub Pages

Settings → Pages → Deploy from a branch → `main` / root.

## Structure

- `index.html`: markup, styles and scripts
- `assets/<project>/`: images and videos for each case study
- `assets/studio/`: studio logo animation, nav mark and portrait
